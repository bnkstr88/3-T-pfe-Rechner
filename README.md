# Drei-Töpfe-Rechner

Installierbare Web-App für einen Entnahmeplan mit drei Töpfen: Geldmarkt-ETF für die nächsten Raten, Anleihen als Krisenvorrat und ein weltweiter Aktien-ETF für den Rest. Gerechnet wird über 2.000 mögliche Zukünfte von Börse und Inflation, mit fester oder flexibler Rate, Härtetests nach echten Krisen und einmaligen Zahlungen. Die Steuer wird wie im echten Depot gerechnet (Abgeltungsteuer, Teilfreistellung, Sparerpauschbetrag, Vorabpauschale), mit festen Annahmen. Das Ergebnis lässt sich als PDF speichern.

- Deutsch: `index.html`, Englisch: `en.html` (Three-Pot Calculator). Oben rechts lässt sich die Sprache wechseln.
- Startet mit Beispielwerten (700.000 €, 1.200 € netto im Monat, 50 bis 90). Eigene Eingaben werden nur lokal im Browser des Geräts gespeichert, nichts geht an einen Server. „Zurücksetzen“ stellt die Beispielwerte wieder her.
- Läuft nach dem ersten Öffnen auch offline.
- Installieren: iPhone in Safari → Teilen → „Zum Home-Bildschirm“. Android in Chrome → „App installieren“.

Wie gerechnet wird: [Bericht](https://docs.google.com/document/d/1t_N1LzJy00f9xf8Ud4zb32VG49ytxX75-RGW-vCxJis/edit)
